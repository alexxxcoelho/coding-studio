Le mémo de familiarisation

Pourquoi cette étape

Lire l'entretien en entier avant de poser le moindre code évite de découper trop tôt un discours qu'on n'a pas encore compris. Le mémo garde la trace de ce qui frappe à la première lecture, avant que le codebook n'oriente le regard. [Références méthodologiques]

Ce que vous faites

  1. Lire l'entretien en entier.
  2. Répondre aux questions du modèle de mémo.
  3. Ajouter une question si l'entretien l'exige.
Dans Coding Studio
Dans la Bibliothèque, l'inspecteur de l'entretien choisit le modèle de mémo. À l'étape Coder, l'onglet Mémo de l'inspecteur reçoit les réponses ; « Ajouter une question » vaut pour cet entretien seulement. Le modèle lui-même se modifie dans Paramètres de l'étude.
Ouvrir l'étape CoderOuvrir les paramètres de l'étude

Pièges fréquents

  • Coder pendant la première lecture.
  • Recopier le résumé de l'entretien au lieu de noter ses propres réactions.

Ce qui sort de cette étape

Un mémo daté, rattaché à l'entretien, exporté avec lui.
