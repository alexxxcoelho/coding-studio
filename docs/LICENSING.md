A notice by itself is not complete compliance.
- Choose the section 4/6 source-provision option appropriate to the actual source and binary distribution. A generic upstream URL is not a substitute for providing the corresponding source for a modified distributed version.

There is no commercial-use surcharge or separate marketing-endorsement requirement.
