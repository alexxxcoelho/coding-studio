# Glossary {#glossaire}

The terms are listed alphabetically by their English name.

## A to C {#glossaire-a-c}

**AI review (Revue IA).** Optional re-reading of an interview by a language model, done blind. It is a check on reading, not a measure of reliability between coders.

**Arbitration (Arbitrage).** The decision you make for each disagreement between your coding and the model's. It is justified, final and kept separately.

**Blind (À l'aveugle).** Said of the AI review: the model receives the turns and the codebook, never your codes.

**Cell (Cellule).** A box in the matrix, at the intersection of a row and a column. It holds a closed value (present, not mentioned, contradicted, uncertain), a number of passages and an optional one-line summary.

**Code (Code).** A label attached to a passage to say what it contains. It has a stable identifier, a free name, a definition (includes, excludes), an optional parent, an origin and a history.

**Codebook.** All the codes, as a tree, with their definitions and its version.

## D to M {#glossaire-d-m}

**Disagreement (Désaccord).** A unit where the model and you did not attach the same codes.

**End-of-interview checklist (Liste de contrôle de fin d'entretien).** A set of editable tick boxes, reviewed after coding an interview.

**Evidence type (Nature de la preuve).** Description of a quoted passage: first-hand account, reported speech, quantified estimate, cited document, opinion. It describes; it does not rank. Two other qualifications accompany it: the origin (spontaneous, prompted, taken from a document, inferred) and the role (trigger, after-the-fact justification, enabling condition, constraint, undetermined).

**Final audit (Audit final).** Submission check: three statements drawn at random, whose trail to the source passages must be shown without manual reconstruction.

**Fingerprint (Empreinte).** A number computed from the content of a file (SHA-256). It changes if the file changes.

**Focused code (Code focalisé).** A broader code that groups descriptive codes (concrete, close to the respondent's words). It is usually the parent in the tree.

**Highlight (Surlignage).** A passage kept without a code. It is used to build codes and can become a candidate quotation.

**Interpretive framework (Cadre d'interprétation).** An optional theoretical grid (none by default; TOE, TAM/UTAUT or custom) used to read themes. It appears only in the "Analyse" (Analyser) and "Write" (Rédiger) stages.

**Interview attribute (Attribut d'entretien).** A characteristic of an interview (library type, role, status of the statements) defined in "Settings" (Réglages) and filled in on the record. It serves as a filter or a matrix row.

**Later (Plus tard).** The system code (LATER) for what is still in doubt. The units concerned are listed so they can be reviewed.

**Link type (Type de lien).** The relation between a passage and a part of the text: supports, qualifies, conditions, mechanism, exception, contradicts. The list is editable.

**Manifest (Manifeste).** The file in an export package that lists every file with its size and fingerprint.

**Matrix (Matrice).** A table that crosses rows (interviews, cases, an attribute) and columns (themes, focused codes, custom dimensions).

**Memo (Mémo).** A dated analytical text. A distinction is made between the familiarisation memo (before coding), the end-of-interview memo, the code memo and a theme's decision memo.

**Memo template (Modèle de mémo).** The list of questions of the familiarisation memo, defined in Settings. Several templates are possible.

**Merge (Fusion).** Replacing one code with another, with all its units recoded. Not to be confused with placing a code under a parent, which changes no coding.

## N to Z {#glossaire-n-z}

**Not mentioned (Non évoqué).** A cell value: the subject did not come up in the interview. This does not mean it is absent in reality.

**Not relevant (Non pertinent).** The state of a respondent turn that adds nothing to the study. Key N, marked NA.

**Passage (Passage).** A portion of text, with its exact position, selected within a turn. It is the coding unit. A code attached without a selection covers the whole turn.

**Project template (Modèle de projet).** A JSON file that exports your settings (without data) to start a new study.

**Pseudonymisation (Pseudonymisation).** Replacement of the names of people and organisations with pseudonyms, in your transcripts and in any text sent to a model.

**Reference (Référence).** A coded passage. Seven references in two interviews do not make seven respondents.

**Theme (Thème).** An analytical proposition built from codes, which answers a research question. It is not a topic.

**Turn (Tour).** A speaker's contribution, cut at a maximum length (150 words by default). It is the container and the navigation unit (numbered U042 on the "Coding" (Coder) screen).
