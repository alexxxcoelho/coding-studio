# Glossaire {#glossaire}

Les termes sont rangés par ordre alphabétique.

## A à C {#glossaire-a-c}

**Arbitrage.** Décision que vous prenez pour chaque désaccord entre votre codage et celui du modèle. Elle est motivée, finale et conservée à part.

**Attribut d'entretien.** Caractéristique d'un entretien (type de bibliothèque, rôle, statut des propos) définie dans les Réglages et remplie dans la fiche. Elle sert de filtre ou de ligne de matrice.

**À l'aveugle.** Se dit de la revue IA : le modèle reçoit les tours et le codebook, jamais vos codes.

**Audit final.** Contrôle de remise : trois affirmations tirées au hasard, dont le chemin jusqu'aux passages sources doit se montrer sans reconstitution manuelle.

**Cadre d'interprétation.** Grille théorique facultative (aucun par défaut ; TOE, TAM/UTAUT ou personnalisé) qui sert à lire les thèmes. Elle n'apparaît qu'aux étapes Analyser et Rédiger.

**Cellule.** Case de la matrice, à l'intersection d'une ligne et d'une colonne. Elle porte une valeur fermée (présent, non évoqué, contredit, incertain), un nombre de passages et un résumé facultatif d'une ligne.

**Code.** Étiquette posée sur un passage pour dire ce qu'il contient. Il porte un identifiant stable, un nom libre, une définition (inclut, exclut), un parent éventuel, une origine et un historique.

**Code focalisé.** Code plus large qui regroupe des codes descriptifs (concrets, proches des mots du répondant). C'est en général le parent dans l'arbre.

**Codebook.** L'ensemble des codes, en arbre, avec leurs définitions et sa version.

## D à M {#glossaire-d-m}

**Désaccord.** Unité où le modèle et vous n'avez pas posé les mêmes codes.

**Empreinte.** Nombre calculé sur le contenu d'un fichier (SHA-256). Elle change si le fichier change.

**Fiche de thème.** Dossier de défense d'un thème : proposition, questions, codes, cas, cas divergents, conditions, interprétation alternative, limites, statut, mémo de décision.

**Fusion.** Remplacement d'un code par un autre, avec recodage de toutes ses unités. À ne pas confondre avec le fait de placer un code sous un parent, qui ne change aucun codage.

**Lien (type de).** Relation entre un passage et une partie du texte : soutient, nuance, conditionne, mécanisme, exception, contredit. La liste est modifiable.

**Liste de contrôle de fin d'entretien.** Série de cases à cocher, modifiable, passée en revue après le codage d'un entretien.

**Manifeste.** Fichier d'un paquet d'export qui liste tous les fichiers avec leur taille et leur empreinte.

**Matrice.** Tableau qui croise des lignes (entretiens, cas, attribut) et des colonnes (thèmes, codes focalisés, dimensions personnalisées).

**Mémo.** Texte daté d'analyse. On distingue le mémo de familiarisation (avant codage), le mémo de fin d'entretien, le mémo de code et le mémo de décision d'un thème.

**Modèle de mémo.** Liste de questions du mémo de familiarisation, définie dans les Réglages. Plusieurs modèles sont possibles.

**Modèle de projet.** Fichier JSON qui exporte vos réglages (sans données) pour démarrer une nouvelle étude.

## N à Z {#glossaire-n-z}

**Nature de preuve.** Description d'un passage cité : récit de première main, propos rapporté, estimation chiffrée, document cité, opinion. Elle décrit, elle ne classe pas. Deux autres qualifications l'accompagnent : l'origine (spontané, sollicité, tiré d'un document, inféré) et le rôle (déclencheur, justification après coup, condition facilitatrice, contrainte, indéterminé).

**Non évoqué.** Valeur de cellule : le sujet n'est pas venu dans l'entretien. Cela ne veut pas dire qu'il est absent dans la réalité.

**Non pertinent.** État d'un tour du répondant qui n'apporte rien à l'étude. Touche N, marqué NA.

**Passage.** Portion de texte, avec sa position exacte, que vous sélectionnez dans un tour. C'est l'unité de codage. Un code posé sans sélection couvre le tour entier.

**Plus tard.** Code système (LATER) pour ce qui hésite. Les unités concernées se listent pour être revues.

**Pseudonymisation.** Remplacement des noms de personnes et d'organisations par des pseudonymes, dans vos transcriptions et dans tout texte envoyé à un modèle.

**Référence.** Un passage codé. Sept références dans deux entretiens ne font pas sept répondants.

**Revue IA.** Relecture facultative d'un entretien par un modèle de langage, à l'aveugle. C'est un contrôle de lecture, pas une mesure de fiabilité entre codeurs.

**Surlignage.** Passage retenu sans code. Il sert à construire les codes et peut devenir une citation candidate.

**Thème.** Proposition analytique construite à partir de codes, qui répond à une question de recherche. Ce n'est pas un sujet.

**Tour.** Prise de parole d'un locuteur, coupée à une longueur maximale (150 mots par défaut). C'est le conteneur, l'unité de navigation (numérotée U042 dans l'écran Coder).
